# tractionhq.com

Static marketing site for TractionHQ. It's plain HTML, CSS and JS with no build step.

- `index.html`: the page
- `styles.css`: styles
- `script.js`: mobile nav, scroll reveal, stat count-up
- `assets/favicon.svg`: logo mark

Preview locally with `python3 -m http.server` and open http://localhost:8000.
Deploy by pointing Netlify, Vercel, Cloudflare Pages or GitHub Pages at the repo root.

## Before launch
- Replace the `[X]` placeholders in the **Results** section with real, client-approved case studies.
- Set the form `action` in `#book` (currently `https://formspree.io/f/your-form-id`) to your form endpoint, or swap it for a Calendly/Cal.com embed.
- Confirm the service claims (≈2-week launch, month-to-month) and `hello@tractionhq.com`.
